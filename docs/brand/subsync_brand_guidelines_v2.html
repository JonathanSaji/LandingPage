04 — Motion & Animation Rules
1
Only animate transform and opacity — never transition-all, never color or width
2
Entrance animations use cubic-bezier(0.16, 1, 0.3, 1) — overshoot spring feel
3
Stagger delays: eyebrow 0.15s → headline lines 0.4/0.6/0.8s → subhead 1.2s → CTAs 1.5s
4
Scroll reveals: translateY(40px) → 0 with opacity 0→1, triggered at 80% viewport threshold
5
Background SVG paths use stroke-dashoffset animation only — no fill transitions
6
Every interactive element needs hover + focus-visible + active states — no exceptions
